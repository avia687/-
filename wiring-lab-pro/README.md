# מעבדת EV

כלי לימוד, התקנה, אבחון ובנייה למערכות חשמל באופניים ובקורקינטים חשמליים: 12 דגמים, מודל תלת-ממדי, אבחון לפי מדידות, יומן תיקונים, כרטיסי כלי ו״בנה בעצמך״. עובד בלי רשת, הנתונים נשמרים רק במכשיר.

## הרצה

```bash
node build.mjs            # בונה את dist/
node verify-report.mjs    # DATA-VERIFY.md + PRICES-VERIFY.md
tests/run-all.sh          # כל בדיקות הקבלה (Playwright)
```

| פלט | מה זה |
|---|---|
| `dist/web/` | **הגרסה לפריסה (PWA).** CSP קשיח `default-src 'self'`, בלי קוד inline, בלי CDN, עובד בלי רשת, ניתן להתקנה. מעלים את התיקייה כמו שהיא לכל אחסון סטטי עם HTTPS (Netlify / Cloudflare Pages – `_headers` כבר בפנים). |
| `dist/index.html` | קובץ יחיד לפתיחה ישירה בדפדפן (בלי Service Worker). |
| `dist/artifact.html` | אותו קובץ לתצוגה מוטמעת ב-claude.ai (Three.js מ-cdnjs עם SRI). |
| `dist/models.json`, `dist/components.json` | נתוני הדגמים וקטלוג הרכיבים. |

**עדכון מחירים ורכיבים:** עורכים רק את `src/components.json` (או `dist/web/components.json` בשרת). האפליקציה טוענת את הגרסה החדשה אם `updatedAt` חדש יותר והקובץ עובר בדיקה.

## מבנה

`src/base.html` (המערכת המקורית) לא נערך ידנית. `build.mjs` מוסיף שכבות ומחיל תיקוני חיבור שכל אחד חייב להתאים בדיוק פעם אחת. ה-build נכשל אם נשאר `style=""`, סקריפט inline, `on*=`, אימוג׳י בממשק, או מחיר בלי תאריך ומקור.

|---|---|
| `p06_sec.js` | ולידציה, JSON בטוח, סכמות, Vault (AES-GCM + PBKDF2 250k) |

## לאימות לפני שימוש מסחרי

- `DATA-VERIFY.md` – כל נתון ⚠️ טיפוסי / ❓ לא ידוע, לכל דגם ולערכי החישוב.
- `PRICES-VERIFY.md` – כל טווחי המחירים (כולם הערכה, לא מאומתים).
- `LEGAL-REVIEW.md` – טענות משפטיות וסעיפים לעורך דין (המסמכים המשפטיים הם טיוטה).
- `SECURITY.md` – טבלת איומים ומגבלות.

## מגבלות ידועות

- ה-CSP הקשיח חל על `dist/web` בלבד; בגרסת ה-Artifact הקוד inline.
- בתצוגה המוטמעת הדפדפן חוסם הדפסה, הורדה ו-Web Share – מופיעה תיבת העתקה.
- זיהוי דיבור תלוי בדפדפן (Chrome שולח את הקול לשרת שלו – מוצג גילוי נאות, כבוי כברירת מחדל).
- ההסתברויות, שעות העבודה וטווחי המחירים הם הערכות – מסומנים ככאלה.
