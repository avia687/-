# מעבדת החיווט Pro

שדרוג של מעבדת החיווט (12 הדגמים) לכלי מקצועי: שתי רמות משתמש, אקדמיה, אבחון מבוסס מדידות עם מנוע הסתברות, כלים לטכנאים ואשף עם אימות מדידה.

## איך בונים

```bash
node build.mjs            # dist/index.html, dist/artifact.html, dist/models.json
node verify-report.mjs    # DATA-VERIFY.md – כל נתון ⚠️/❓
```

`dist/index.html` נפתח ישירות בדפדפן. תלות חיצונית יחידה: Three.js r128 מ-cdnjs (ו-Heebo מ-Google Fonts). בלי רשת או בלי WebGL – כל הפאנלים עובדים, רק המודל התלת-ממדי לא מוצג.

## מבנה

הקובץ המקורי `src/base.html` לא נערך ידנית. ה-build מוסיף עליו שכבות, ומחיל תיקוני חיבור קטנים שכל אחד מהם חייב להתאים בדיוק פעם אחת – אחרת ה-build נכשל.

| קובץ | תפקיד |
|---|---|
| `src/base.html` | המערכת המקורית: State, M(), LAYOUT(), vehicleComps(), harness(), שלושה בוני 3D, omit |
| `src/pro-data.json` | סיבות, מדידות, סבירויות, תנאי ״לסירוגין״, מילון, אנלוגיות, הרחבות לאשף, מומנטים, מקרא אמינות |
| `src/models-ext.json` | הרחבה לכל 12 הדגמים: מחברים, פרוטוקול צג, קודים, משקלי תקלות, דגלי מפרט |
| `src/academy.json` | 7 מודולים × 4 שיעורים + בוחן (מפוענח רק בפתיחה הראשונה) |
| `src/p07_core_pro.js` | רמות (מתחיל/מקצוען/מהיר), מצב סדנה, מילון עם tooltip, אמינות ✅/⚠️/❓, יומן תיקונים |
| `src/p08_diag_engine.js` | מנוע Bayes: הסתברויות, ״מה למדוד עכשיו״ (Information Gain), הוכחה לכל מסקנה |
| `src/p09_diag_ui.js` | אבחון לפי מדידות, ריבוי סימפטומים, לסירוגין + Wiggle Test, נקודות בדיקה, אסקלציה |
| `src/p10_academy.js` | אקדמיה: שיעורים לפי רמה ודגם, בוחנים, תעודות |
| `src/p11_meter_sim.js` | סימולטור מולטימטר על המודל, כולל טעויות מסוכנות ותרגיל ״מצאו את התקלה״ |
| `src/p12_tools.js` | מחשבונים, יומן תיקונים + JSON + דו״ח, השוואה ותאימות, בדיקת מפרט, מצב סדנה |
| `src/p13_wizard_plus.js` | אשף: תנאים מקדימים, ״אל תעשו״, מומנטים, אימות מדידה בכל שלב |
| `src/p14_boot_pro.js` | אתחול השכבה החדשה ואז האתחול המקורי |
| `build.mjs` | מחשב לכל דגם testPoints, expectedValues, hallSequence, dataConfidence, torque ומחבר הכול |

כל פיצ'ר עובר דרך `vehicleComps()`, ולכן `omit` מסתיר רכיבים בכל המסכים: שיעורים, מדידות, סיבות, נקודות בדיקה, תרחישי אשף, Wiggle וסימולטור.

## בדיקות קבלה (עברו אוטומטית ב-Playwright)

לכל אחד מ-12 הדגמים (korshidi, onebikeX4, starkMach5, hunterX2, alphaGT, mateX, oxo, thunder3, g30, g2, xiaomi4pro, light2):

- [x] לימוד: לשונית הדגם עם תגיות אמינות, מילון (37 מונחים), אקדמיה – 7 מודולים, כל השיעורים, בוחן ותעודה
- [x] אשף: כל התרחישים הזמינים לדגם עוברים מתחילה ועד סוף; כל שלב נעול עד לבדיקת האימות (65/58/59 שלבים לפי הדגם)
- [x] אבחון: מדידות, ריבוי סימפטומים, הסתברויות חיות, סיכום, ״לא נמצא״, לסירוגין, נקודות בדיקה, קודים
- [x] 3D: הדגשת רכיב וכבל מכל מדידה, נקודת בדיקה, סיבה ושיעור
- [x] נקודות בדיקה: 14–20 לדגם, כולן של רכיבים שקיימים בדגם
- [x] מחשבונים: טווח, טעינה, צניחה, הספק, סוללה חלופית, XsYp
- [x] omit: MATE X בלי מצערת (אין מדידות, תרחיש ושיעור מצערת), קורקינטים בלי PAS, מטען מובנה (G30/G2) בלי מדידת מטען, אזעקה רק בדגמים שיש להם
- [x] בלי WebGL / בלי רשת: כל 12 הדגמים עוברים את כל המסכים
- [x] מובייל 390px: Bottom Sheet, יעדי מגע ≥44px (pointer: coarse), מצב סדנה
- [x] יומן תיקונים: הוספה, עריכה, מחיקה בשני שלבים, דו״ח ללקוח, ייצוא וייבוא JSON (מיזוג)
- [x] מנוע האבחון: 10 תרחישים קלאסיים מגיעים לסיבה הנכונה (למשל Hall תקוע → חיישן Hall 70%)

## מגבלות ידועות

- הדפסה והורדת קובץ עובדות כשפותחים את `dist/index.html` בדפדפן. בתצוגה מוטמעת (Artifact) הדפדפן חוסם אותן – שם מופיעה תיבת טקסט להעתקה.
- ה״lazy-load״ של האקדמיה הוא פענוח מושהה של JSON שמוטמע בקובץ (אין שרת לטעינה נפרדת בקובץ יחיד).
- ההסתברויות הן הערכה הנדסית (⚠️), לא סטטיסטיקת שירות.
- הנתונים שדורשים אימות מול היצרן מפורטים ב-`DATA-VERIFY.md`.
