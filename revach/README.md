# רווח (Revach) — מעקב עבודות והכנסות

אפליקציית מובייל שמרכזת את כל העבודות שעשית, מראה כמה הרווחת, נותנת תובנות,
ומאפשרת לחסוך למטרות (חופשה, פלייסטיישן, טיול...) עם הקצאה מכל עבודה.

100% צד־לקוח — הנתונים נשמרים על המכשיר (localStorage), בלי שרת ובלי הרשמה.

## פיצ'רים
- **בית** — כמה הרווחת השבוע, השוואה לשבוע שעבר, יעד שבועי, תובנות ועבודות אחרונות.
- **הוספת עבודה ב-10 שניות** — מה עשית · למי · כמה · תאריך · שולם/ממתין. שדות אופציונליים: שעות עבודה והוצאות. עם קיצורים ללקוחות ועבודות אחרונים.
- **תובנות** — שכר שעתי ממוצע, רווח נטו (אחרי הוצאות), וגרפים: מגמת 6 שבועות, הכנסה לפי יום בשבוע, לקוחות מובילים, שולם מול ממתין.
- **דוח חודשי** — ניווט בין חודשים, סיכום הכנסות/נטו/ממתין, **ייצוא לאקסל (CSV)** ו**שיתוף בוואטסאפ**.
- **תזכורות תשלום** — כרטיס בבית עם עבודות שלא שולמו, סימון "באיחור" מעל שבועיים, וכפתור סימון כשולם. סינון עבודות ממתינות.
- **מטרות** — יעד + אמוג'י, והקצאה מכל עבודה (אחוז או סכום קבוע). פס התקדמות + הערכת זמן ליעד.
- מצב כהה/בהיר, RTL מלא, גיבוי/ייצוא נתונים.

## הרצה
זהו אתר סטטי — פשוט פותחים את `index.html` בדפדפן (גם בטלפון).

```
open index.html
```

## מבנה
- `index.html` — שלד הדף
- `styles.css` — עיצוב (מובייל, RTL, מצב כהה)
- `app.js` — כל הלוגיקה (נתונים, תובנות, מטרות)
- `build-single.mjs` — מאחד הכל לקובץ יחיד (`revach-app.html`) לפרסום/שיתוף
- `test.mjs` / `test-single.mjs` — בדיקות דפדפן אוטומטיות (Playwright)
