# API

The API is **REST‑first**, documented live via **OpenAPI/Swagger** at `GET /docs` (generated by
`@nestjs/swagger` from the controller decorators). A **GraphQL** schema is designed below; the
codebase is structured so a `@nestjs/graphql` code‑first layer can be added over the same services.

## Auth

All endpoints except `/auth/*` and `/health` require `Authorization: Bearer <accessToken>`.
Tokens are obtained from `/auth/login` or `/auth/register` and rotated via `/auth/refresh`.

```
POST /auth/register   { tenantName, email, password, name? }      → { accessToken, refreshToken }
POST /auth/login      { email, password, tenantSlug? }            → { accessToken, refreshToken }
POST /auth/refresh    { refreshToken }                            → { accessToken, refreshToken }
```

## REST resources

### Products
```
GET    /products?page&pageSize&status&search      list (tenant-scoped, paginated)
GET    /products/:id                               get one
POST   /products                                   create            [STORE_OWNER, MANAGER]
POST   /products/import   { supplierId, externalId }  import via supplier adapter
PATCH  /products/:id                               update            [STORE_OWNER, MANAGER]
PATCH  /products/:id/archive                        archive           [STORE_OWNER, MANAGER]
```

### Suppliers
```
GET    /suppliers                                  list
POST   /suppliers   { name, provider, externalId? } create           [STORE_OWNER, MANAGER]
GET    /suppliers/catalog?provider&keyword          search provider catalog (adapter)
```

### Orders
```
GET    /orders?page&pageSize&status                list
GET    /orders/:id                                  get one
POST   /orders   { items:[{variantId,quantity}], shippingCents?, ... }  create
POST   /orders/:id/fulfill                          place w/ supplier + open fulfillment
```

### AI agent  `[STORE_OWNER, MANAGER]`
```
POST /ai/product-description  { productTitle, features?, brandVoice?, targetAudience? }
                              → { description }
POST /ai/seo                  { productTitle, category?, keywords? }
                              → { title, metaDescription, keywords[], slug }
POST /ai/profitability        { unitCostCents, shippingCents, feeRate?, targetMargin?, competitorPriceCents? }
                              → { recommendedPriceCents, grossMarginPct, netMarginPct, breakdown, rationale }
POST /ai/research             { niche, market?, count? }
                              → { ideas: [{ name, rationale, estimatedDemand, suggestedPriceCents }] }
```

### Health
```
GET /health   → { status, db, time }
```

## Error envelope

```json
{ "statusCode": 400, "error": "message or validation details", "timestamp": "2026-..." }
```

## Example

```bash
# 1. Login (after seeding)
TOKEN=$(curl -s localhost:4000/auth/login -H 'content-type: application/json' \
  -d '{"email":"owner@demo.com","password":"password123"}' | jq -r .accessToken)

# 2. List products
curl -s localhost:4000/products -H "authorization: Bearer $TOKEN"

# 3. AI profitability (needs ANTHROPIC_API_KEY set on the API)
curl -s localhost:4000/ai/profitability -H "authorization: Bearer $TOKEN" \
  -H 'content-type: application/json' \
  -d '{"unitCostCents":1200,"shippingCents":300,"feeRate":0.05,"targetMargin":0.4}'
```

## GraphQL schema (designed)

REST is the implemented surface. The equivalent GraphQL schema (code‑first, addable over the same
service layer) would look like:

```graphql
type Query {
  products(page: Int, pageSize: Int, status: ProductStatus, search: String): ProductPage!
  product(id: ID!): Product
  orders(page: Int, pageSize: Int, status: OrderStatus): OrderPage!
}

type Mutation {
  createProduct(input: CreateProductInput!): Product!
  importProduct(supplierId: ID!, externalId: String!): Product!
  createOrder(input: CreateOrderInput!): Order!
  fulfillOrder(id: ID!): Order!
  aiProductDescription(input: ProductDescriptionInput!): AiTextResult!
  aiProfitability(input: ProfitabilityInput!): ProfitabilityResult!
}

type Product {
  id: ID!
  title: String!
  status: ProductStatus!
  basePriceCents: Int!
  currency: String!
  variants: [ProductVariant!]!
}
```
