# סורק הסוחרים של Polymarket 🔍📈

אתר שמתחבר ל‑API הציבורי של **Polymarket**, סורק אותו ומדרג את הסוחרים הכי
רווחיים. בלחיצה על סוחר נפתח דף פרופיל עם הפוזיציות הפתוחות שלו, הפעילות
האחרונה, וכפתור **"עקוב אחרי הסוחר"** + רשימת מעקב אישית.

## מה הוא עושה

- **סורק** את לוח המובילים של Polymarket (רווח + נפח מסחר).
- **מדרג** כל סוחר בציון מורכב (0–100) על בסיס רווח, תשואה (ROI) ונפח.
- **סינון ומיון**: חלון זמן (יום/שבוע/חודש/הכל), רווח מינימלי, נפח מינימלי,
  חיפוש לפי שם/כינוי/ארנק.
- **דף סוחר**: שווי תיק, רווח לא‑ממומש, אחוז הצלחה, פוזיציות פתוחות ("מה הוא
  מחזיק עכשיו") ופעילות אחרונה כ"איתותי העתקה".
- **מעקב (Watchlist)**: כפתור "עקוב" לכל סוחר, נשמר בדפדפן.

## הרצה מקומית

```bash
cd polymarket
npm install
npm start
# פתח http://localhost:4010
```

## מצבי נתונים

האתר עובד מיד גם בלי גישה ל‑Polymarket:

- **live** (ברירת מחדל) – מושך נתונים חיים מ‑Polymarket. אם ה‑API לא נגיש
  (פיירוול, סביבת פיתוח חסומה וכו') – עובר אוטומטית לנתוני דמו ריאליסטיים.
  התווית בראש הדף מציינת אם הנתונים חיים או דמו.
- **demo** – כפה נתוני דמו בלבד (ללא קריאות רשת):

  ```bash
  DATA_MODE=demo npm start
  ```

## משתני סביבה

ראה `.env.example`. עיקריים: `PORT`, `DATA_MODE`, `CACHE_TTL_MS`.

## API

| נתיב | תיאור |
|------|-------|
| `GET /api/traders?window=&sort=&minProfit=&minVolume=&q=&limit=` | רשimת סוחרים מדורגת |
| `GET /api/traders/:wallet` | פרטי סוחר (פוזיציות, פעילות, שווי) |
| `GET /api/health` | בדיקת חיות |

## פריסה (Deploy)

פרויקט Node עצמאי. ב‑Railway/Render/Fly וכו':

- Build: `npm install`
- Start: `npm start`
- הפלטפורמה מזריקה `PORT` אוטומטית.

> ⚠️ אין כאן ייעוץ השקעות. מסחר בשווקי חיזוי כרוך בסיכון.
