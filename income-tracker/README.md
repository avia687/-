# מעקב הכנסות · הקרון

אפליקציית עמוד יחיד (עברית, RTL) למעקב אחר ההכנסות, **מסונכרנת עם מערכת ההזמנות של הקרון**.

## שני מצבי עבודה
האפליקציה מזהה לבד לאיזה מצב לעבור:

- **מסונכרן עם הקרון** — כשפותחים אותה דרך שרת הקרון (בכתובת `/income`).
  כל הזמנה חדשה שנכנסת נרשמת אוטומטית כהכנסה, והדף מתעדכן כל 15 שניות.
- **מצב מקומי** — כשפותחים את `index.html` לבד (למשל ב-GitHub Pages).
  הנתונים נשמרים בדפדפן (`localStorage`), עם ייצוא/ייבוא JSON לגיבוי.

## תכונות
- **סיכום יומי** — סה״כ הכנסה, מספר הזמנות, ממוצע להזמנה, והמנות הכי מוזמנות באותו יום (עם בורר תאריך).
- כרטיסי סיכום: החודש, השנה, סה״כ, ממוצע חודשי.
- גרף עמודות של 6 החודשים האחרונים ופילוח לפי קטגוריה.
- טבלת תנועות עם סימון מקור (הזמנה מהקרון / ידני), סינון ומחיקה.
- הוספת הכנסה ידנית (מזומן, טיפים וכו').
- מצב בהיר/כהה.

## הפעלה מסונכרנת (עם הקרון)
מריצים את השרת הראשי ונכנסים לכתובת `/income`:

```bash
npm run install:all
npm start
# ואז לפתוח: http://localhost:3001/income
```

בפרודקשן (Railway) הכתובת תהיה `https://<your-app>/income`.

## הפעלה עצמאית (בלי שרת)
פשוט פותחים את `income-tracker/index.html` בדפדפן — עובד במצב מקומי.

## איך הסנכרון עובד (טכני)
- `POST /api/orders` (יצירת הזמנה) → רושם אוטומטית הכנסה דרך `services/salesStore.js`.
- `GET  /api/income` — כל התנועות (הזמנות + ידני).
- `GET  /api/income/summary?date=YYYY-MM-DD` — סיכום יומי (סה״כ, מספר הזמנות, מנות מובילות).
- `POST /api/income` — הוספת הכנסה ידנית.
- `DELETE /api/income/:id` — מחיקת תנועה.

הנתונים נשמרים בקובץ `server/data/sales.json` (מוחרג מ-git). על תשתית עם דיסק זמני
כמו Railway כדאי בהמשך לחבר בסיס נתונים קבוע כדי לשמור היסטוריה בין דיפלויים.
