# מעקב הכנסות · Income Tracker

אפליקציית עמוד יחיד (עברית, RTL) למעקב אחר הכנסות. עובדת לגמרי בדפדפן — ללא שרת וללא התקנה.

## תכונות
- הוספת הכנסות עם סכום, תאריך, תיאור וקטגוריה
- כרטיסי סיכום: החודש, השנה, סה״כ וממוצע חודשי
- גרף עמודות של 6 החודשים האחרונים
- פילוח לפי קטגוריה
- טבלת תנועות עם סינון לפי חודש/קטגוריה ומחיקה
- שמירה מקומית ב-`localStorage` (הנתונים נשארים בדפדפן שלך בלבד)
- ייצוא/ייבוא גיבוי בפורמט JSON
- מצב בהיר/כהה

## הפעלה
פשוט פותחים את `index.html` בדפדפן — זהו. אין תלויות ואין שלב build.

לתצוגה דרך שרת מקומי (אופציונלי):

```bash
npx serve income-tracker
# או
python3 -m http.server --directory income-tracker 8080
```

## גיבוי הנתונים
הנתונים נשמרים מקומית בדפדפן. השתמשו בכפתור **ייצוא** כדי לשמור קובץ JSON,
וב-**ייבוא** כדי לשחזר אותו (בכל דפדפן/מכשיר).
